# Harmony
## An online messaging app

Harmony began as a project for a Web Development course another student and I were taking in Drexel University.
We decided to collaborate on a socket-based messaging app for our final project.
Although the feature set is minimal, we spent a lot of time getting the fundamentals down in terms of the socket functionality and DOM manipulation.
It was tricky work, but it was rewarding!

I am going to continue work on this as a personal side-project, hopefully replacing my use of Discord if I can find a way to deploy it safely and effectively.
